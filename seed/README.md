# Демонстрационный слепок данных

`demo.dump` — состояние базы рабочего стенда на 2026-08-06, в формате
`pg_dump -Fc`. Нужен, чтобы новое развертывание сразу показывало заполненные
экраны, а не пустые в ожидании первого планового сбора.

Разворачивается одной командой:

```bash
bash scripts/seed-restore.sh
```

## Что внутри

| | |
|---|---|
| Сценарии | 1852: каталог наблюдения и скользящая сетка витрины |
| Снимки рынка | 2908 |
| Расчеты | 2914 |
| Предложения | 119 048 |
| Период наблюдений | 2026-08-06, одни сутки |
| Размер | 24 МБ |

Цены собраны после исправления семи дефектов отбора, найденных сверкой с
сайтами источников, и после правок 6 августа — отбор предложений, свежесть
данных, класс вагона, учет пропущенных источников. Более ранние слепки этого
репозитория содержат завышенные примерно вдвое авиацены и **непригодны для
демонстрации**.

## Чем этот слепок отличается от прежних

**История — одни сутки, а не трое.** База стенда обнулена 6 августа: данные
предыдущих дней были собраны и пересчитаны кодом с четырьмя дефектами, часть
из них молчаливыми, и отличить верные числа от неверных в них уже нельзя.
Подробности — в [снимке состояния](../docs/PROJECT_STATE.md).

Практическое следствие для демонстрации: **блоки динамики и сравнения за
период будут пусты**. «Изменение за 1 день», «за 7 дней», кривые динамики
стоимости и сезонность требуют истории, которой в слепке нет. Уровни цен,
сравнение направлений, витрина «Куда поехать», разбор расчета и сравнение
источников работают полностью.

Если демонстрация должна показывать динамику, слепок надо пересобрать не
раньше, чем на стенде накопится несколько суток наблюдений.

## Чего внутри нет и почему

**Предложения — только по последнему снимку каждого сценария.** Полная история
наблюдений весит на порядок больше и в репозиторий не помещается. Срез
покрывает все экраны, которые читают предложения: переплату у агента, разброс
цен и надбавки. Расчеты и снимки лежат целиком.

**Учетные записи.** Слепок публичный, а хеши паролей рабочего стенда — нет.
Пользователи создаются заново из `BOOTSTRAP_*_PASSWORD` вашего `.env`:
`seed-restore.sh` вызывает `bootstrap` сразу после восстановления.

**Аудит, сырые ответы источников и HTML-снимки.** События аудита содержат
адреса и user-agent, сырые ответы — выдачу Туту и РЖД целиком. Ни то, ни другое
не нужно для демонстрации и не должно лежать в открытом репозитории. Ссылки на
них у снимков обнулены.

**Журнал задач.** Описывает работу стенда, а не состояние рынка, и на целевой
установке ссылался бы в пустоту.

**Кэш результатов.** Воспроизводится сам, срок жизни — 45 минут.

## Обновление слепка

Собирается скриптом на узле стенда:

```bash
bash scripts/seed-build.sh
```

Рабочая база при этом не меняется: сборка идет через временную базу `tco_seed`,
которая удаляется следом. Скрипт печатает состав слепка и **не коммитит его** —
проверьте числа и добавьте файл вручную.

Учтите, что каждое обновление добавляет в историю git еще один двоичный файл на
десятки мегабайт. Обновляйте по необходимости, а не по расписанию.
